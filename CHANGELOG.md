# Changelog

## 1.1.0 — 2026-10-04

- Package the existing local UXP/MCP bridge as a portable source project.
- Generate private per-install settings, Codex configuration, and a local CCX.
- Add diagnostics, installation/troubleshooting guidance, and GitHub CI.
- Make result acknowledgments repeatable after a lost HTTP response.
- Stop the panel safely when a restarted server no longer recognizes a result.
- Validate configuration and malformed JSON-RPC input.

## 1.0.0 — Existing local source

- UXP polling panel and Node.js MCP server with four tools and timeout tracking.
