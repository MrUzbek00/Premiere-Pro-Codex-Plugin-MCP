# Distribution

This is a clone-and-setup source distribution. GitHub hosting does not install anything in Premiere or configure Codex. Users install the prerequisites, run setup, install the generated panel, and configure local MCP as described in the README.

The local CCX has the token for the machine on which setup ran. It is convenient for that machine's Creative Cloud installation but must not be shipped as a shared public release. A shared binary would require a separate pairing/settings workflow, which this project does not implement.

Keep `.gitignore` in the repository. Source archives generated by GitHub from committed files are appropriate distribution artifacts. Do not manually ZIP the whole working folder after setup. Review the staged file list before pushing, especially if files have previously been force-added.

The retained plugin ID supports upgrading the existing personal bridge. It is not an Adobe Marketplace registration. Marketplace publishing, signing, Adobe review, and a public binary pairing flow are outside this source package.
